1️⃣ Giới thiệu

UDP (User Datagram Protocol) là giao thức không kết nối (connectionless) — nghĩa là không cần bắt tay hay duy trì phiên làm việc như TCP.
UDP gửi dữ liệu đi dưới dạng datagram (gói tin) và không đảm bảo rằng gói tin sẽ đến nơi hoặc đến đúng thứ tự.

Tuy nhiên, nhờ sự đơn giản và tốc độ cao, UDP thường được sử dụng trong:

  • Game online (nơi tốc độ quan trọng hơn độ chính xác tuyệt đối)
  • IoT và cảm biến mạng (sensor network)
  • Streaming video hoặc audio
  • Ứng dụng broadcast dữ liệu

Trong Java, UDP được hỗ trợ qua hai lớp chính trong gói java.net:

  • DatagramSocket: để gửi hoặc nhận gói dữ liệu.
  • DatagramPacket: đại diện cho gói tin UDP.

2️⃣ UDP Server – Lắng nghe gói tin

Server UDP chỉ cần mở cổng và chờ nhận dữ liệu, không cần thiết lập kết nối.

import java.net.*;

public class UDPServer {
    public static void main(String[] args) throws Exception {
        DatagramSocket server = new DatagramSocket(5000);
        byte[] buf = new byte[1024];

        System.out.println("Server UDP đang lắng nghe tại cổng 5000...");

        DatagramPacket packet = new DatagramPacket(buf, buf.length);
        server.receive(packet);

        String msg = new String(packet.getData(), 0, packet.getLength());
        System.out.println("Nhận từ client: " + msg);

        server.close();
    }
}

Giải thích:

  • DatagramSocket(5000) mở cổng 5000 để lắng nghe.
  • receive() chờ một gói tin đến (chặn chương trình cho đến khi có dữ liệu).
  • Dữ liệu được lấy ra từ packet.getData() và packet.getLength().

3️⃣ UDP Client – Gửi gói tin

Client gửi gói dữ liệu đến địa chỉ và cổng của server mà không cần bắt tay.

import java.net.*;

public class UDPClient {
    public static void main(String[] args) throws Exception {
        DatagramSocket client = new DatagramSocket();
        String msg = "Xin chào UDP Server!";

        DatagramPacket packet = new DatagramPacket(
            msg.getBytes(),
            msg.length(),
            InetAddress.getLocalHost(),
            5000
        );

        client.send(packet);
        System.out.println("Đã gửi: " + msg);
        client.close();
    }
}

Khi chạy:

  • Chạy UDPServer trước.
  • Sau đó chạy UDPClient.
  • Server sẽ nhận và hiển thị thông điệp gửi từ client.

4️⃣ Khi nào nên dùng UDP?

Tình huống Có nên dùng UDP không?
Game online, streaming video Rất phù hợp (ưu tiên tốc độ)
Ứng dụng chat hoặc API Nên dùng TCP để đảm bảo dữ liệu
Gửi dữ liệu cảm biến IoT Rất hiệu quả
Truyền file hoặc dữ liệu lớn Dễ mất gói, không phù hợp

5️⃣ Kết luận

UDP là một giao thức đơn giản nhưng mạnh mẽ, đóng vai trò quan trọng trong các hệ thống yêu cầu tốc độ cao và độ trễ thấp. Vì không duy trì kết nối, UDP giúp giảm tải tài nguyên mạng, phù hợp khi bạn cần gửi dữ liệu liên tục như cảm biến, luồng âm thanh, hoặc gói tin game thời gian thực. Tuy nhiên, “tốc độ đi cùng với rủi ro” — UDP không đảm bảo an toàn hoặc thứ tự dữ liệu, do đó:

  • Bạn cần tự cài đặt cơ chế xác nhận (ACK) nếu cần chắc chắn dữ liệu đến nơi.
  • Hoặc kết hợp với TCP trong những phần quan trọng để cân bằng giữa tốc độ và độ tin cậy.
  • Ngoài ra, nên giới hạn kích thước gói tin (~64 KB) để tránh lỗi phân mảnh mạng.
