1️⃣ Lập trình mạng là gì?

Lập trình mạng (Network Programming) cho phép các chương trình gửi và nhận dữ liệu qua mạng bằng các giao thức như TCP và UDP.
Trong Java, việc này được hỗ trợ thông qua các lớp trong gói java.net, ví dụ:

  • Socket và ServerSocket cho TCP (truyền dữ liệu đáng tin cậy).
  • DatagramSocket và DatagramPacket cho UDP (truyền nhanh, không cần kết nối lâu dài).

Nhờ đó, bạn có thể xây dựng ứng dụng giao tiếp hai chiều giữa các máy tính, từ chat app, API nội bộ cho đến IoT.

2️⃣ Mô hình Client – Server trong Java

Hầu hết các ứng dụng mạng đều dựa trên mô hình Client – Server:

  • Server: Lắng nghe yêu cầu từ client, xử lý và phản hồi.
  • Client: Gửi yêu cầu đến server và nhận phản hồi.

Ví dụ đơn giản:

Server.java Và Client.java

import java.io.*;
import java.net.*;

public class Server {
    public static void main(String[] args) throws IOException {
        ServerSocket serverSocket = new ServerSocket(8080);
        System.out.println("Server đang lắng nghe tại cổng 8080...");

        Socket socket = serverSocket.accept();
        System.out.println("Client đã kết nối!");

        DataInputStream input = new DataInputStream(socket.getInputStream());
        String message = input.readUTF();
        System.out.println("Client gửi: " + message);

        input.close();
        socket.close();
        serverSocket.close();
    }
}

import java.io.*;
import java.net.*;

public class Client {
    public static void main(String[] args) throws IOException {
        Socket socket = new Socket("localhost", 8080);
        System.out.println("Kết nối đến server thành công!");

        DataOutputStream output = new DataOutputStream(socket.getOutputStream());
        output.writeUTF("Xin chào Server!");
        output.flush();

        output.close();
        socket.close();
    }
}

Giải thích

  • ServerSocket: dùng để tạo cổng lắng nghe, chờ kết nối từ client.
  • Socket: là kết nối thực tế giữa Server và Client sau khi bắt tay thành công.
  • InputStream / OutputStream: giúp đọc và ghi dữ liệu qua kết nối mạng.
  • DataInputStream / DataOutputStream: là lớp bọc thêm giúp gửi nhận dữ liệu kiểu nguyên thủy dễ dàng hơn.

👉 Khi bạn chạy Server.java trước, sau đó chạy Client.java, bạn sẽ thấy Server nhận được thông điệp “Xin chào Server!” — đó chính là quá trình giao tiếp mạng hai chiều qua giao thức TCP.

3️⃣ Lợi ích khi học lập trình mạng với Java

Việc học lập trình mạng không chỉ giúp bạn hiểu sâu hơn về Internet mà còn mở ra rất nhiều cơ hội phát triển:

  1. Hiểu rõ cách dữ liệu di chuyển trong mạng máy tính
    – Nắm được cơ chế truyền nhận, định tuyến, đóng gói dữ liệu.

  2. Xây dựng ứng dụng có khả năng kết nối Internet
    – Như hệ thống chat, game online, hoặc công cụ quản lý thiết bị từ xa.

  3. Cơ sở để học các công nghệ nâng cao
    – RESTful API, WebSocket, RMI, hay Microservices đều dựa trên nền tảng Socket.

  4. Phát triển ứng dụng thời gian thực (real-time)
    – Dành cho lĩnh vực IoT, streaming, hoặc ứng dụng cộng tác đa người dùng.

4️⃣ Kết luận

Lập trình mạng trong Java giúp bạn:

  • Hiểu rõ cách máy tính và chương trình giao tiếp với nhau qua Internet.
  • Có thể tự tạo client – server và xử lý dữ liệu giữa các thiết bị.
  • Xây dựng nền tảng vững chắc cho các ứng dụng phân tán hoặc dịch vụ web.
