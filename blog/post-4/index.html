Quản lý địa chỉ mạng với InetAddress trong Java

1️⃣ Giới thiệu

Khi làm việc với lập trình mạng, một trong những yêu cầu cơ bản là xác định và quản lý địa chỉ IP của thiết bị hoặc máy chủ.
Trong Java, lớp InetAddress trong gói java.net được thiết kế để làm việc với:

  • Địa chỉ IP (IPv4 / IPv6)
  • Tên máy (hostname)
  • Phân giải tên miền (DNS lookup)

Bạn có thể sử dụng InetAddress để:

  • Lấy thông tin của máy cục bộ (localhost).
  • Phân giải tên miền → địa chỉ IP.
  • Kiểm tra tính khả dụng của máy chủ qua phương thức isReachable().

2️⃣ Ví dụ cơ bản với InetAddress

Ví dụ dưới đây minh họa cách lấy thông tin máy hiện tại và phân giải IP của website:

import java.net.*;

public class NetworkInfo {
    public static void main(String[] args) throws Exception {
        // Lấy thông tin máy cục bộ
        InetAddress local = InetAddress.getLocalHost();
        System.out.println("Tên máy cục bộ: " + local.getHostName());
        System.out.println("Địa chỉ IP cục bộ: " + local.getHostAddress());

        // Lấy thông tin của một domain cụ thể
        InetAddress google = InetAddress.getByName("google.com");
        System.out.println("Tên miền: " + google.getHostName());
        System.out.println("Địa chỉ IP của Google: " + google.getHostAddress());
    }
}

Giải thích:

  • InetAddress.getLocalHost() → trả về thông tin IP của chính máy đang chạy chương trình.
  • InetAddress.getByName(“google.com”) → thực hiện phân giải DNS để tìm IP thật của tên miền.
  • getHostName() và getHostAddress() → lần lượt lấy tên máy và địa chỉ IP.

3️⃣ Ứng dụng thực tế của InetAddress

Lớp InetAddress rất hữu ích trong nhiều tình huống mạng:

  1. Kiểm tra kết nối Internet → Dùng để xác định xem thiết bị có thể truy cập một địa chỉ từ xa không.
InetAddress google = InetAddress.getByName("google.com");
boolean reachable = google.isReachable(3000);
System.out.println("Có thể kết nối đến Google: " + reachable);

  1. Viết chương trình “ping” đơn giản → Đo thời gian phản hồi của một server hoặc thiết bị mạng.

  2. Quản lý danh sách máy trong mạng LAN → Có thể kết hợp vòng lặp quét dải IP (ví dụ 192.168.1.x) để tìm các thiết bị đang hoạt động.

  3. Tích hợp với hệ thống giám sát mạng hoặc IoT → Xác định thiết bị nào đang online, offline, hoặc phản hồi chậm.

4️⃣ Kết luận

Lớp InetAddress là bước khởi đầu quan trọng để hiểu DNS, địa chỉ IP, và kết nối mạng trong Java. Nó là nền tảng cho các ứng dụng như:

  • Công cụ kiểm tra mạng,
  • Hệ thống client-server,
  • Ứng dụng IoT hoặc giám sát thiết bị.
