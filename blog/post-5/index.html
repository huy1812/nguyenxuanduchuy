1️⃣ Tổng quan

TCP (Transmission Control Protocol) là giao thức hướng kết nối (connection-oriented), đảm bảo dữ liệu được truyền đúng thứ tự và không bị mất mát.

Khi bạn cần trao đổi thông tin ổn định và chính xác như:

  • Ứng dụng chat thời gian thực 🗨️
  • API nội bộ giữa các dịch vụ
  • Web service hoặc hệ thống giao tiếp hai chiều

→ TCP luôn là lựa chọn hàng đầu.

Trong Java, bạn sẽ làm việc với hai lớp chính trong gói java.net:

  • ServerSocket: dùng để lắng nghe và chấp nhận kết nối.
    -SServe: dùng để gửi và nhận dữ liệu giữa client – server.

2️⃣ Ví dụ: Gửi và nhận dữ liệu song công (Full-Duplex)

Trong TCP, cả hai bên Client và Server đều có thể gửi – nhận dữ liệu cùng lúc.
Ví dụ dưới đây minh họa cách Client gửi thông điệp và Server phản hồi lại.

import java.io.*;
import java.net.*;

public class TCPClient {
    public static void main(String[] args) throws IOException {
        Socket socket = new Socket("localhost", 8085);
        BufferedReader in = new BufferedReader(
            new InputStreamReader(socket.getInputStream()));
        PrintWriter out = new PrintWriter(socket.getOutputStream(), true);

        out.println("Xin chào từ Client!");
        String response = in.readLine();
        System.out.println("Phản hồi từ Server: " + response);

        socket.close();
    }
}

import java.io.*;
import java.net.*;

public class TCPServer {
    public static void main(String[] args) throws IOException {
        ServerSocket serverSocket = new ServerSocket(8085);
        System.out.println("Server đang chạy tại cổng 8085...");

        Socket socket = serverSocket.accept();
        BufferedReader in = new BufferedReader(
            new InputStreamReader(socket.getInputStream()));
        PrintWriter out = new PrintWriter(socket.getOutputStream(), true);

        String msg = in.readLine();
        System.out.println("Client gửi: " + msg);
        out.println("Server đã nhận: " + msg);

        socket.close();
        serverSocket.close();
    }
}

Giải thích

  • Server mở cổng và chờ kết nối (ServerSocket.accept()).
  • Client kết nối đến server (new Socket(“localhost”, 8085)).
  • Hai bên trao đổi dữ liệu bằng luồng (InputStream / OutputStream).

3️⃣ Xử lý nhiều Client cùng lúc

Khi có nhiều Client kết nối, Server cần tạo thread riêng cho mỗi Client để tránh nghẽn. Ví dụ:

while (true) {
    Socket socket = serverSocket.accept();
    new Thread(() -> handleClient(socket)).start();
}

private static void handleClient(Socket socket) {
    try {
        BufferedReader in = new BufferedReader(
            new InputStreamReader(socket.getInputStream()));
        PrintWriter out = new PrintWriter(socket.getOutputStream(), true);

        String msg = in.readLine();
        System.out.println("Nhận từ client: " + msg);
        out.println("Phản hồi từ server: " + msg);
        socket.close();
    } catch (IOException e) {
        e.printStackTrace();
    }
}

Với mô hình này:

  • Mỗi Client có luồng xử lý riêng biệt.
  • Server có thể phục vụ nhiều kết nối đồng thời.
  • Đây là nền tảng cho các ứng dụng chat đa người dùng hoặc websocket server.

4️⃣ Ưu điểm của TCP

Tính năng Mô tả
Độ tin cậy cao Dữ liệu được đảm bảo truyền đúng thứ tự, không mất gói.
Dễ quản lý Cấu trúc đơn giản, dễ cài đặt cơ chế xác thực hoặc mã hóa SSL.
Hỗ trợ song công Gửi và nhận dữ liệu cùng lúc (Full-Duplex).
Phù hợp cho ứng dụng thời gian thực Chat, hệ thống điều khiển, giám sát mạng, API.

5️⃣ Kết luận

TCP là nền tảng của Internet hiện đại — hầu hết các website, API, và ứng dụng client-server đều dựa vào nó. Việc nắm vững lập trình Socket TCP nâng cao giúp bạn:

  • Hiểu rõ cơ chế giao tiếp mạng hai chiều.
  • Tự xây dựng hệ thống chat nhiều người, máy chủ API, hoặc ứng dụng giám sát.
  • Là bước đệm để học WebSocket, RMI, hay Microservices.
